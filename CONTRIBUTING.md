# Mitwirken

Dieses Projekt ist eine deutsche Ausgabe von [ai-job-search](https://github.com/MadsLorentzen/ai-job-search) (MIT) von Mads Lorentzen, angepasst für die Jobsuche in Deutschland.

Fehler und Verbesserungsvorschläge sind als Issue willkommen. Bitte keine persönlichen Daten posten: keine Lebensläufe, Anschreiben, Tracker-Auszüge oder Stellenlisten.

Vor einem Pull Request:

```bash
python3 -m pytest
```

Änderungen an den Portal-Werkzeugen (`.agents/skills/*-search`) bitte mit einem Test, der den Fehler zeigt.
